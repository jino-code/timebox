# Timebox

## 概要

予定とタスクをタイムライン上で一元管理して、1日のキャパシティを可視化するタスク管理アプリ。

## 開発背景

### 1. アプリ間の分断によって、予定とタスクを一元管理できないこと。

**課題**  
ToDoアプリやカレンダーアプリを行ったり来たりして、今日やるべきことを把握するのに手間がかかる。

**解決策**  
予定とタスクをタイムライン上で一元管理して、1つのアプリ上で全体像を把握できるようにする。

### 2. 時間の見積もり不足によって、計画が破綻してしまうこと。

**課題**  
時間の概念がないToDoアプリでは、24時間という物理的なキャパシティを考慮せず、理想的にタスクを入れてしまう。

**解決策**  
タスクに見込み時間をつけ、キャパシティを超過したら警告を出すことで、気づきを与える。

### 3. 計画が崩れた後のリカバリの難しさが、アプリからの離脱を招くこと。

**課題**  
予定通りに進まなかった時、全タスクを手動で組み直す手間がかかりすぎる。未完了タスクが積み重なることで自己嫌悪に陥り、アプリを離脱またはリセットしてしまう。

**解決策**  
「〇時以降を押し出す」という明示的な操作で、指定時刻以降のタスクを一括で後ろ倒しにできる。
また、「インボックスに戻す」か「別日に移す」という逃げ道を用意することで、再構築の手間を減らしつつユーザーが主導権を持って計画を立て直せるようにする。

## MVP

- 日次ビュー
- 週次ビュー
- インボックス
- 2タップ移動UI
- キャパシティ超過アラート
- 認証（Supabase Auth）

## 技術スタック

- フロントエンド / バックエンド: TypeScript / Next.js
- ミドルウェア: Supabase（PostgreSQL・Auth・RLS）
- インフラ: Vercel
- CI/CD: GitHub Actions
- テスト: Vitest
