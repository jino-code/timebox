## 概要

予定とタスクをタイムライン上で一元管理して、1日のキャパシティを可視化するタスク管理アプリ。

## 開発背景

タスク管理にNotion、スケジュール管理にGoogleカレンダーを使っていたが、2つのアプリを行き来する中で今日の全体量が把握しづらいという課題を感じていた。1つのアプリに統合することを検討したが、既存ツールにはそれぞれ限界があった。Notionはタスクの管理は柔軟にできる一方、時間軸の概念がなくスケジュール管理には不向きだった。Googleカレンダーは時間を入れることが前提になっていて、とりあえずタスクを列挙しておくという使い方ができず、リスケの際は日時を再入力する手間がかかり直感的でなかった。
また、24時間という物理的な制約を無視して理想でタスクを詰め込んでしまい、結局こなせないという経験を繰り返していた。
これらの課題を解決するために、予定とタスクをタイムライン上で一元管理し、1日のキャパシティを可視化するTimeboxを開発することにした。

## MVP

- 日次ビュー
- 週次ビュー
- インボックス
- 2タップ移動UI
- キャパシティ超過アラート
- 認証（Supabase Auth）
